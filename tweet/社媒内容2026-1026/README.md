# 14 周社媒内容包

面向 LinkedIn、Facebook 与 Instagram 的 B2B 化妆品原料内容。第 1–4 周为基础定位，第 5–14 周继续覆盖等级、质量、工艺、供应商与 RFQ 沟通。

## 第 5–14 周主题

| 周次 | 主题 | 核心问题 |
| --- | --- | --- |
| 5 | 透明质酸等级选择 | 分子量、形态和规格是否适配配方 |
| 6 | 烟酰胺规格与杂质 | 不只看 assay，还要看杂质与文件 |
| 7 | 表面活性剂选择 | 活性物、体系温和性与形态 |
| 8 | 防腐体系评估 | 防腐剂不能脱离配方环境选择 |
| 9 | 化妆品色粉与分散 | CI、表面处理与分散方式 |
| 10 | 乳化剂与工艺 | 乳化体系必须结合工艺条件 |
| 11 | 供应商审核与变更 | 文件、产线与变更控制 |
| 12 | 样品到商业批次 | 样品确认后仍要锁定批次标准 |
| 13 | 储存包装与物流 | 包装完整性和储运条件 |
| 14 | RFQ 需求清单 | 用完整信息提升寻源效率 |

每周目录均包含平台文案、独立主题图和视频脚本；视频成片暂不生成。公开表达统一为：目录仅展示部分精选原料。客户可以提供名称、INCI、CAS、等级或规格，我们结合中国化妆品原料制造与供应链，协助评估相关寻源选项、样品和可用技术资料。

## 转化路径

1. **互动**：评论、投票、收藏或回答一个具体技术问题。
2. **资料领取**：仅在第 1、5、9、13 周启用；用户主动私信关键词，或通过带 UTM 的网站页面直接下载。评论不触发自动私信。
3. **正式询盘**：需求已经明确时，再进入网站联系表单。

执行矩阵见 `CTA三级转化与证据规范.md`，可领取资料位于 `resources/`。

## 证据原则

- 不把 AI 概念图当作真实工厂、客户、批次或检测记录。
- 只发布已经获得授权并完成脱敏的真实截图、照片、表格或文件片段。
- 没有真实案例授权时，必须标注 `Illustrative scenario`，不能写成已完成的客户项目。
- 证据优先展示过程：需求澄清、规格对齐、文件核对、样品追踪和变更记录。
- 不购买互动，不使用批量账号评论，不向评论者自动发送商业私信。
- 发送用户主动索取的资料后不自动追加销售消息；只有用户继续询问或明确同意后才跟进。
- 回复应根据用户问题个性化，不连续复制粘贴同一段营销内容。
