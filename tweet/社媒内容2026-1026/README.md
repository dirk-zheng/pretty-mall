# 14 周社媒内容包

面向 LinkedIn、Facebook 与 Instagram 的 B2B 化妆品原料内容。第 1–4 周为基础定位，第 5–14 周继续覆盖等级、质量、工艺、供应商与 RFQ 沟通。

## 第 5–14 周主题

| 周次 | 主题 | 核心问题 |
| --- | --- | --- |
| 5 | 透明质酸等级选择 | 分子量、形态和规格是否适配配方 |
| 6 | 烟酰胺规格与杂质 | 不只看 assay，还要看杂质与文件 |
| 7 | 表面活性剂选择 | 活性物、体系温和性与形态 |
| 8 | 防腐体系评估 | 防腐剂不能脱离配方环境选择 |
| 9 | 化妆品色粉与分散 | CI、表面处理与分散方式 |
| 10 | 乳化剂与工艺 | 乳化体系必须结合工艺条件 |
| 11 | 供应商审核与变更 | 文件、产线与变更控制 |
| 12 | 样品到商业批次 | 样品确认后仍要锁定批次标准 |
| 13 | 储存包装与物流 | 包装完整性和储运条件 |
| 14 | RFQ 需求清单 | 用完整信息提升寻源效率 |

每周目录均包含平台文案、独立主题图和视频脚本；视频成片暂不生成。公开表达统一为：结合中国化妆品原料制造与供应链，协助客户寻找目录内外的原料、样品和技术资料。
