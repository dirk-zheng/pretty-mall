# 真实工作镜头处理

拍摄目标：用真实、克制、可以解释的工作画面，展示需求澄清、文件核对、工厂沟通和样品追溯过程。不要拍成泛化的“高端实验室宣传片”，也不要用摆拍或 AI 图片冒充实际工作证据。

## 镜头 1｜收到一条不完整需求

- 景别：桌面俯拍，4:5 竖图。
- 画面：电脑或打印稿上只有原料简称、预估数量和一句用途说明。
- 动作：工作人员用笔圈出缺失的 `INCI / CAS / Grade / Specification / Destination`。
- 表达：客户最初提供的信息还不能直接询价。
- 脱敏：公司名、姓名、邮箱、电话、价格全部遮挡。
- 建议文案：`A product name is a starting point—not yet a sourcing brief.`

## 镜头 2｜需求澄清前后对比

- 景别：固定机位，左右分屏或同一张桌面的两份表格。
- Before：只有贸易名和数量。
- After：补充 INCI、CAS、等级、关键规格、应用、数量、包装和目的地。
- 动作：手将 Before 表格替换为 After 表格。
- 表达：不是简单转发询盘，而是把需求整理为供应商能够一致理解的采购条件。
- 发布边界：只能使用获得授权且完成脱敏的真实业务记录；没有真实记录时必须标注 `Illustrative workflow`，不能写成客户案例。

## 镜头 3｜同一 INCI 的等级核对

- 景别：近景，镜头对准两份已脱敏的规格表。
- 画面：两份文件显示相同 INCI，但等级、含量、杂质、形态或检测方法不同。
- 动作：用透明尺、便签或手指依次指出不同字段。
- 表达：相同 INCI 不代表可以直接比较价格。
- 连续拍摄：
  1. 两份文件同框；
  2. 关键差异特写；
  3. 完成后的比较表。
- 建议文案：`Same INCI. Different grade. Different comparison basis.`

## 镜头 4｜文件关联检查

- 景别：45° 侧俯拍。
- 画面：桌面摆放 `Specification / TDS / SDS / COA`，旁边是一张核对清单。
- 动作：逐项确认等级名称、制造商、版本日期、检测方法和批号关联。
- 表达：文件数量多，不代表已经对应到同一产品。
- 脱敏：遮盖供应商名称、证书编号、完整批号和签名。
- 避免：不要随意摆放空白纸或无关文件冒充技术资料。

## 镜头 5｜与工厂确认问题

- 景别：人物肩后镜头，只拍手、笔记本和电脑局部。
- 画面：屏幕或纸上展示真实问题清单，例如：
  - Exact manufacturer and site?
  - Assay method?
  - Sample lot and matching COA?
  - Commercial MOQ?
  - Change notification?
- 动作：工作人员在沟通后标记 `Confirmed / Pending / Need document`。
- 表达：展示具体沟通和核实过程，不只拍“正在开会”的空镜头。
- 脱敏：聊天头像、联系人、电话号码和工厂名称不得入镜。

## 镜头 6｜样品接收和身份登记

- 景别：中近景加标签特写。
- 画面：真实样品瓶、内部样品编号、收样日期和登记表。
- 动作：检查外观与封口，粘贴内部编号，再在记录表中关联 COA。
- 表达：样品不是一瓶无身份的原料，而是可追溯的评估对象。
- 脱敏：内部编号只保留部分信息，不展示完整供应商批号。
- 建议文案：`A sample needs an identity before it can support a decision.`

## 镜头 7｜样品到商业批次的交接

- 景别：桌面横向构图，同时补拍一版 4:5 竖图。
- 画面：从左到右排列 `Approved sample → Matching COA → Commercial grade → Purchase requirement`。
- 动作：用线条或便签连接制造商、等级、样品编号、包装和商业订单字段。
- 表达：样品认可后，还要确认商业供货是否来自相同制造来源和等级。
- 建议文案：`Sample approval is a checkpoint. Traceable handover comes next.`

## 统一拍摄标准

- 主格式使用 4:5 竖图，分辨率至少 2160×2700。
- 手机使用 1×镜头，避免超广角造成文件和包装变形。
- 固定相机位置，主要通过手部动作形成画面变化。
- 使用窗边自然光或一盏柔光灯，避免彩色灯光。
- 保留适度的真实工作痕迹，同时移除水杯、个人物品和无关品牌。
- 每个场景拍三种画面：环境、操作和细节。
- 每个场景额外拍摄一段 5–8 秒无声素材，供后续动图或转场使用；当前不安排视频发布。
- 原始图、脱敏图和发布图分别保存，不在唯一原图上直接覆盖。

## 首批拍摄顺序

优先完成镜头 1、3、5、6、7。这五组可支撑需求澄清、等级比较、工厂沟通、样品管理和商业批次衔接等多篇内容。

发布前必须再次检查授权范围和脱敏状态，不公开客户或供应商名称、联系人、邮箱、电话、价格、订单号、完整批号、证书编号、详细地址及未经许可的工厂信息。
