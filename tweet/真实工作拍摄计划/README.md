# 真实工作证据执行区

这里用于把真实业务过程转化为可公开的社媒证据，不存放虚构客户案例。

## 发布门槛

素材同时满足以下条件后，才可移入 `approved/` 并排期：

1. 来源是真实询盘、样品、文件核对或供应商沟通过程。
2. 已取得公司内部发布许可；涉及第三方时已确认授权范围。
3. 已删除客户/供应商名称、联系人、邮箱、电话、地址、价格、订单号、完整批号和证书编号。
4. 脱敏后仍能证明一个具体工作动作，例如补齐规格、比对文件版本或连接样品与批次。
5. 文案不把单次工作记录外推成普遍能力或供应承诺。

## 文件状态

- `需求澄清前后对比-发布模板.md`：待填真实记录，未填前禁止发布。
- `拍摄计划.md`：现场拍摄清单与构图要求。
- `素材登记表.md`：授权、脱敏和渠道许可记录。

原始素材只应保存在公司批准的受控位置；本目录只保存已脱敏版本和登记信息。
